# Read3d

A 3D file reader for Windows. Drop in an FBX, OBJ, GLB/glTF, USD, STL, PLY, DAE, BLEND or Houdini file and see every mesh, material, texture and transform inside it, with no import and no viewport.

**Download:** the latest installer is on the [Releases](https://github.com/matridge/Read3d/releases/latest) page.

More at [matridge.com/read3d](https://matridge.com/read3d).
